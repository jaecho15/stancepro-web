(*) Definición Índice Ultravioleta

El índice UV señala la capacidad de la radiación UV solar de producir lesiones en la piel. Vale la pena aclarar que no siempre la cantidad de luz ambiental va relacionada con el índice UV. En la tabla se presenta el valor entero mas cercano mediante una escala que comienza en 0, pero que no dispone de un límite superior. A continuación se muestra el sistema estándar para presentar la medición de este parámetro:

Valores que se transmiten

  • Índice UV: Valor instantáneo registrado a la hora indicada.
  • Temperatura del Aire (°C): Valor instantáneo registrado a la hora indicada.
  • Humedad Relativa (%): Valor instantáneo registrado a la hora indicada.
  • Velocidad Viento (km/h): Valor máximo registrado en el intervalo de 60' previo a la hora indicada.
  • Dirección Viento: Dirección de la máxima velocidad registrada en el intervalo de 60' previo a la hora indicada.
  • Presión Atmosférica (mBar o Hpa): Valor instantáneo registrado a la hora indicada.
  • Precipitación (mm): Valor acumulado a la hora indicada, desde las 6:00 de la mañana.
  • Altura Río (m): Valor instantáneo registrado a la hora indicada.
